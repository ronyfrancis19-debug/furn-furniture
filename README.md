# McMullen Furniture

A responsive seven-page React and Vite redesign for McMullen Furniture, inspired by the supplied furniture-store reference.

The site includes Home, About Us, Sofas & Recliners, Bedding & Mattresses, Bedroom Sets, Dining & Entertainment, and Contact. Financing details are included on the Home and Contact pages. The original seven McMullen brand pages are linked from the brand directory on the Home and About pages.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

Brand links open the corresponding McMullen brand pages, the Facebook page and map links open their respective destinations, and the contact form link opens McMullen's existing form. Product and room photography is loaded from Unsplash.
